# Aplikasi Manajemen Peserta Praktikum (React Dasar)

React + JavaScript (.jsx) dengan Vite.

## Cara menjalankan

```bash
npm install
npm run dev
```

Buka alamat yang muncul di terminal (biasanya http://localhost:5173).

Cek build produksi: `npm run build`

## Catatan
- Data hanya disimpan di state; reload halaman mengembalikan 3 data awal.
- Komponen: App, FormPeserta, FilterPeserta, DaftarPeserta, ItemPeserta, RingkasanPeserta (folder `src/components`).
